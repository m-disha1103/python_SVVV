>> A "graph" typically refers to either a visual representation of data (like a chart) or a fundamental mathematical network structure made of vertices and edges.
>> Graph is a non-linear data structure like tree data structure. 
>> A Graph is composed of a set of vertices(V) and a set of edges(E). 
>> The vertices are connected with each other through edges.
>> A Graph is a non-linear data structure used to represent relationships between objects.
A graph consists of:
> Vertices (Nodes): The objects.
> Edges: The connections between the objects.
Example:

    A
   / \
  B---C
   \
    D
Vertices = A, B, C, D
Edges = (A,B), (A,C), (B,C), (B,D)

Types of Graphs
1) Undirected Graph
Edges have no direction.
A ----- B
 \     /
   C
Example:
Facebook friendships
2) Directed Graph (Digraph)
Edges have directions.
A → B
↓   ↑
C → D
Example:
Instagram followers
One-way roads
3) Weighted Graph
Each edge has a weight (cost/distance).
A --5-- B
 \      |
 2      3
  \     |
    C
Example:
Google Maps
4) Unweighted Graph
All edges have equal weight.
5) Cyclic Graph
Contains at least one cycle.
A → B
↑   ↓
D ← C
6) Acyclic Graph
Contains no cycles.
Example:
Family tree
7) Connected Graph
Every node is reachable from every other node.
8) Disconnected Graph
A --- B

C --- D
>> Graph Representation
1. Adjacency Matrix
For graph:
A -- B
|    |
C -- D
|   | A | B | C | D |
| - | - | - | - | - |
| A | 0 | 1 | 1 | 0 |
| B | 1 | 0 | 0 | 1 |
| C | 1 | 0 | 0 | 1 |
| D | 0 | 1 | 1 | 0 |

2. Adjacency List
Space: O(V + E) (most commonly used)

>>Graph Traversal
1. DFS (Depth First Search)
Uses Stack (or recursion).
Time Complexity: O(V + E)

2. BFS (Breadth First Search)
Uses Queue.
Time Complexity: O(V + E)

>>Applications of Graphs
1)Google Maps (shortest path)
2)Social networks (Facebook, LinkedIn)
3)Flight routes
4)Computer networks
5)Recommendation systems
6)Web page linking
7)GPS navigation
Important Interview Algorithms
| Algorithm        | Purpose                                           | Time Complexity  |
| ---------------- | ------------------------------------------------- | ---------------- |
| BFS              | Level-order traversal, shortest path (unweighted) | O(V + E)         |
| DFS              | Traversal, cycle detection                        | O(V + E)         |
| Dijkstra         | Shortest path (positive weights)                  | O((V + E) log V) |
| Bellman-Ford     | Shortest path (negative weights allowed)          | O(VE)            |
| Floyd-Warshall   | All-pairs shortest path                           | O(V³)            |
| Prim's           | Minimum Spanning Tree                             | O(E log V)       |
| Kruskal's        | Minimum Spanning Tree                             | O(E log E)       |
| Topological Sort | Ordering in DAG                                   | O(V + E)         |
